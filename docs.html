Mulai menggunakan Gitflow

Persiapan dan cara membuat perintah

01
Pasang Git

Pastikan Git tersedia di komputer dengan menjalankan git --version.

02
Pilih perintah

Tempel link GitHub jika diperlukan, lalu pilih kategori dan tindakan.

03
Salin dan jalankan

Pilih Bash atau CMD, periksa hasilnya, lalu tempel semua baris di terminal.

Tentang baris perintahTanda && menghubungkan langkah dan menghentikan rangkaian jika langkah sebelumnya gagal. Pilih Bash untuk terminal Bash/Git Bash atau CMD untuk Windows Command Prompt. Jangan gunakan format CMD di PowerShell.

URL yang didukung: https://github.com/pemilik/repo dan git@github.com:pemilik/repo.git. Link ke file atau halaman branch tidak didukung. Perintah lokal seperti status tidak membutuhkan link.

Branch mengikuti branch default dari GitHub jika pemeriksaan berhasil; jika tidak, nilainya main. Isi kolom branch secara manual jika berbeda. Perintah yang memakai URL langsung tidak mengatur remote origin atau upstream otomatis.

Repository

Upload, update, dan sinkronisasi

Perintah Fungsi Perlu link
Upload pertama Inisialisasi Git, stage, commit, lalu push ke branch tujuan. Gunakan repository GitHub kosong. Ya
Update project Stage semua perubahan, commit, lalu push ke branch tujuan. Ya
Clone repository Unduh repository dan masuk ke folder hasil clone. Ya
Pull perubahan Ambil dan gabungkan branch GitHub ke branch lokal yang aktif. Ya
Cek status Lihat branch aktif dan perubahan file lokal. Tidak
Ganti isi branch Commit isi project lokal lalu force push untuk menimpa branch tujuan. Risiko tinggi
Sebelum mengganti isi branchCadangkan repository. Force push menimpa isi dan riwayat branch tujuan di GitHub. Gunakan folder project baru, periksa file dan .gitignore, lalu pastikan URL dan branch benar. Branch lain tidak diubah.

Branch

Kelola cabang lokal dan remote

Perintah Fungsi Catatan
Daftar branch Tampilkan branch lokal dan branch yang aktif. Lokal
Buat branch Buat branch dari posisi saat ini lalu langsung pindah. Lokal
Pindah branch Pindah ke branch lokal yang sudah ada. Lokal
Gabungkan branch Pindah ke branch tujuan, lalu merge branch sumber. Potensi konflik
Hapus branch lokal Hapus branch lokal dengan -d; Git akan menolak jika belum digabung. Menghapus
Hapus branch GitHub Hapus branch pada repository remote yang dipilih. Menghapus

Branch aktif tidak dapat dihapus secara lokal. Branch default atau branch yang dilindungi dapat menolak penghapusan di GitHub.

Pemulihan

Stash, reset, konflik, dan remote

Perintah Fungsi
Simpan sementara Stash perubahan tracked dan untracked; file yang diabaikan tidak disertakan. Perubahan yang disimpan sementara hilang dari working tree.
Pulihkan stash Terapkan stash terbaru dengan apply; salinan stash tetap ada dan konflik mungkin terjadi.
Daftar stash Lihat semua stash lokal.
Batalkan commit Reset soft ke commit sebelumnya; perubahan tetap staged. Hindari pada commit yang sudah dibagikan.
Reset ke GitHub Fetch branch lalu reset hard branch lokal aktif ke hasil fetch.
Periksa konflik Tampilkan file dengan konflik yang belum diselesaikan; tidak menyelesaikannya otomatis.
Ubah remote origin Ganti URL origin yang sudah ada. Jika origin belum ada, perintah akan gagal.
Reset hard bersifat merusakPerubahan pada file yang dilacak akan hilang. File untracked biasanya tetap ada, tetapi dapat terhapus jika menghalangi file yang harus ditulis. Cadangkan seluruh folder terlebih dahulu.

Git lanjutan

Riwayat, diff, tag, dan konfigurasi

Perintah Fungsi
Riwayat commit Tampilkan hingga 20 commit dalam bentuk graph ringkas.
Lihat perubahan Tampilkan diff perubahan yang belum di-stage.
Lihat staged Tampilkan diff yang sudah masuk staging.
Buat dan kirim tag Buat annotated tag pada commit aktif lalu kirim ke repository. Jika push gagal, tag lokal tetap ada.
Periksa .gitignore Cek apakah path relatif diabaikan dan tampilkan aturan yang cocok. Ini tidak mengubah file .gitignore.
Identitas Git Atur nama dan email commit hanya untuk repository lokal ini.

Jika Git membuka tampilan pager saat melihat riwayat atau diff, tekan q untuk keluar.

Repository private

Pemeriksaan akses dan autentikasi

Tanpa token

Gitflow memeriksa akses publik. Respons “tidak ditemukan” juga dapat berarti repository private; keduanya tidak dapat dibedakan tanpa akses.

Dengan token opsional

Buka Akses private, masukkan fine-grained token yang memiliki akses baca metadata ke repository, lalu pilih Periksa akses.

Token hanya dikirim ke GitHub API saat kamu memilih Periksa akses. Token tidak disimpan oleh Gitflow dan tidak dimasukkan ke perintah. Menghapus token atau menutup panel akan mengosongkannya.

Login di terminal tetap diperlukanPemeriksaan di Gitflow tidak mengautentikasi Git. Untuk HTTPS, gunakan credential helper atau metode autentikasi GitHub yang sesuai; untuk SSH, siapkan SSH key. Jangan menempel token ke perintah atau membagikannya.

Batasi akses dan masa berlaku token. Gunakan hanya di perangkat dan browser tepercaya. Panduan token GitHub

Keamanan dan batasan

Hal yang perlu diperiksa sebelum menjalankan perintah

Periksa folder aktif

Jalankan di folder yang diminta. Clone dilakukan dari folder tujuan; sebagian besar perintah lain dari dalam repository.

Periksa isi commit

git add -A memilih semua perubahan yang tidak diabaikan. Periksa git status dan jangan sertakan rahasia.

Cadangkan sebelum tindakan berisiko

Force push, reset, penghapusan branch, dan perubahan riwayat dapat menyebabkan kehilangan data atau memengaruhi rekan kerja.

Ketahui batas pemeriksaan

Gitflow membuat perintah, bukan menjalankannya. Status akses bisa gagal karena jaringan, batas API, izin token, atau repository tidak ditemukan.

Nama branch, pesan, dan path dibatasi agar aman dipakai dalam format Bash dan CMD. Beberapa karakter yang sebenarnya sah di Git sengaja tidak diterima. Nama commit dan file di dalam folder tetap perlu diperiksa sendiri.

Masalah umum

Langkah singkat untuk menanganinya

Repository tidak ditemukan atau private

Periksa pemilik dan nama repository. Jika private, cek dengan token yang memiliki akses. Status ini tidak berarti repository pasti private.

Push ditolak atau branch dilindungi

Periksa apakah branch remote lebih baru atau dilindungi. Ambil perubahan dan selesaikan konflik jika diperlukan; ikuti aturan repository. Jangan langsung force push.

Authentication failed

Pastikan akun, izin, dan autentikasi Git di terminal benar. Password akun GitHub tidak digunakan sebagai password Git melalui HTTPS.

Not a git repository

Pastikan terminal berada di dalam folder repository. Untuk project baru, gunakan Upload pertama.

Commit gagal karena identitas belum diatur

Pilih Identitas Git di kategori Git lanjutan dan isi nama serta email. Perintah tersebut mengatur identitas untuk repository saat ini.

Perintah tidak berhenti atau keluarannya kosong

Jika pager terbuka, tekan q. Perintah diff atau check-ignore bisa tidak menampilkan apa pun jika tidak ada hasil yang cocok.

Gitflow adalah alat independen dan tidak berafiliasi dengan GitHub.
